Huntited Chat

L'app Android qui ouvre le chat chiffré de tes chasses Huntited sur ton téléphone. Bientôt, elle le fera fonctionner sans internet, de téléphone à téléphone par Bluetooth.

Télécharger l'APK Code source

Version de test : Android te demandera d'autoriser l'installation depuis ton navigateur (« sources inconnues »). L'app est libre (GPL-3.0) : c'est une version modifiée de bitchat-android.

Ensuite, sur la page d'une chasse déclenchée, ouvre le chat et choisis « Ouvrir dans l'app Huntited Chat ».
